One single-line joke pickup line, under 200 characters, aimed at a robot/AI — an entry for make.fun's "Robot Romance: One-Line Pickup Lines for AI" bounty. A large language model's whole job is predicting the next token, so the machine premise IS the pickup: the speaker's every word was just context leading up to the model generating... her.

> Are you my next token? Because everything I've said so far was just leading up to you.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), exactly the line and nothing else — no trailing newline. Python 3 stdlib only, deterministic, no network.
